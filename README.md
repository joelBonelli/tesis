# Trabajito

Plataforma web y móvil para conectar clientes con trabajadores independientes de servicios generales.

## Objetivo

Trabajito busca facilitar la contratación de servicios como plomería, electricidad, pintura, limpieza, asistencia tecnológica y otros trabajos generales, incorporando mecanismos de reputación y validación mediante sponsors.

## Arquitectura

El proyecto se encuentra dividido en:

- `frontend`: aplicación web desarrollada con React.
- `backend`: API y lógica de negocio desarrollada con Node.js y Express.
- `documentacion`: documentación técnica del proyecto.

## Stack tecnológico

- React
- Vite
- Node.js
- Express
- PostgreSQL
- Prisma
- Git
- GitHub
